# todo-client (Python SDK for the Todo API)

A small, typed Python client for the [Todo API](../README.md).

```bash
pip install ./sdk          # from the todo-api repo root
```

```python
from todo_client import TodoClient

with TodoClient(api_key="demo-key") as todos:          # http://localhost:8000 by default
    todo = todos.create("Write the docs")
    todos.complete(todo.id)
    print([t.title for t in todos.iter_all()])

# your own server
TodoClient(api_key="demo-key", base_url="http://localhost:8000")
```

## Reference docs

The SDK reference in the docs (`/todo-api/sdk/...`) is generated by Mintlify from
Sphinx's JSON build output, committed at `docs/sdk-artifacts/python/`. After you
change `sdk/todo_client/`, regenerate it from the repo root and commit the result:

```bash
make sdk-docs    # python -m sphinx -b json sdk/docs docs/sdk-artifacts/python
```
