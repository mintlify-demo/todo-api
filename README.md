# Todo API

An in-memory todo list built with [FastAPI](https://fastapi.tiangolo.com/): CRUD, API-key auth with plan tiers, pagination, one deprecated endpoint, one Enterprise-only endpoint, a GraphQL API, a WebSocket event stream, and a Python SDK. Part of the [Mintlify demo org](https://github.com/mintlify-demo): `docs/` holds this API's Mintlify docs.

| Method | Path | Notes |
| --- | --- | --- |
| `GET` | `/todos` | Paginated (`page`, `page_size`), filter with `completed` |
| `POST` | `/todos` | Create |
| `GET` / `PATCH` / `DELETE` | `/todos/{todo_id}` | Read, update, delete |
| `GET` | `/todos/list-all` | **Deprecated**, unpaginated |
| `POST` | `/todos/bulk` | **Enterprise key only**, up to 100 todos |
| `POST` / `GET` | `/graphql` | GraphQL (Strawberry), GraphiQL in the browser |
| `WS` | `/ws/events?api_key=...` | Stream of `todo.created` / `todo.updated` / `todo.deleted` |

All requests need an `X-API-Key` header. The demo keys are public on purpose:

| Key | Plan | Env var to change it |
| --- | --- | --- |
| `demo-key` | standard | `TODO_API_KEY` |
| `partner-demo-key` | partner | `TODO_PARTNER_API_KEY` |
| `enterprise-demo-key` | enterprise (unlocks `POST /todos/bulk`) | `TODO_ENTERPRISE_API_KEY` |

Signed-in docs readers get their plan's key prefilled in the API playground by the [Info API](https://github.com/mintlify-demo/demo-info-api).

## Run it

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload        # http://localhost:8000  (Swagger UI at /docs)
```

```bash
curl -X POST localhost:8000/todos -H 'X-API-Key: demo-key' \
  -H 'Content-Type: application/json' -d '{"title": "Write the docs"}'
```

## Test it

```bash
python -m pytest -q
```

## Regenerate the specs

`docs/openapi.json` (REST) and `docs/schema.graphql` (GraphQL) are committed so Mintlify can build the API references without running the app. After changing `main.py` or `todo_graphql.py`:

```bash
python scripts/export_openapi.py    # or: make spec
```

A test fails if a committed spec is out of date. `docs/asyncapi.yaml` (the WebSocket events) is written by hand; a test checks it lists every event type in `events.py`.

## Python SDK

`sdk/` is the `todo-client` package (`pip install ./sdk`). Its reference in the docs is generated by Mintlify from Sphinx JSON output committed at `docs/sdk-artifacts/python/`. After changing `sdk/todo_client/`, run `make sdk-docs` and commit the result.

## Docs

`docs/` is a complete Mintlify project: guides, the REST reference (OpenAPI), the GraphQL reference (`graphql` in `docs.json`), the WebSocket reference (`asyncapi`), and the SDK reference (`sdk`, format `sphinx`). Two guides are group-gated with `groups` frontmatter (`partner-integrations`, `enterprise-bulk-import`), and `POST /todos/bulk` carries `x-mint.groups: ["enterprise"]` so only Enterprise readers see it. The central [`docs`](https://github.com/mintlify-demo/docs) repo publishes it at `/todo-api`. Preview just this folder with `cd docs && mint dev`.
