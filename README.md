# Todo API

An in-memory todo list built with [FastAPI](https://fastapi.tiangolo.com/): CRUD, API-key auth with plan tiers, pagination, one deprecated endpoint, one Enterprise-only endpoint, a GraphQL API, a WebSocket event stream, and a Python SDK. Part of the [Mintlify demo org](https://github.com/mintlify-demo). Docs: [https://mintlify-demo.mintlify.site/todo-api](https://mintlify-demo.mintlify.site/todo-api).

| Method | Path | Notes |
| --- | --- | --- |
| `GET` | `/todos` | Paginated (`page`, `page_size`), filter with `completed` |
| `POST` | `/todos` | Create |
| `GET` / `PATCH` / `DELETE` | `/todos/{todo_id}` | Read, update, delete |
| `GET` | `/todos/list-all` | **Deprecated**, unpaginated |
| `POST` | `/todos/bulk` | **Enterprise key only**, up to 100 todos |
| `POST` / `GET` | `/graphql` | GraphQL (Strawberry), GraphiQL in the browser |
| `WS` | `/ws/events?api_key=...` | Stream of `todo.created` / `todo.updated` / `todo.deleted` |

All requests need an `X-API-Key` header. The demo keys are public on purpose:

| Key | Plan | Env var to change it |
| --- | --- | --- |
| `demo-key` | standard | `TODO_API_KEY` |
| `partner-demo-key` | partner | `TODO_PARTNER_API_KEY` |
| `enterprise-demo-key` | enterprise (unlocks `POST /todos/bulk`) | `TODO_ENTERPRISE_API_KEY` |

Signed-in docs readers get their plan's key prefilled in the API playground. An Auth0 post-login Action sets it in `/userinfo`, which is Mintlify's Info API URL; see [`auth0/direct-userinfo-action.js`](https://github.com/mintlify-demo/demo-info-api/blob/main/auth0/direct-userinfo-action.js). Nothing is hosted.

## Run it

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload        # http://localhost:8000  (Swagger UI at /docs)
```

```bash
curl -X POST localhost:8000/todos -H 'X-API-Key: demo-key' \
  -H 'Content-Type: application/json' -d '{"title": "Write the docs"}'
```

## Test it

```bash
python -m pytest -q
```

## Python SDK

`sdk/` is the `todo-client` package (`pip install ./sdk`). Its reference in the docs is generated by Mintlify from Sphinx JSON output committed in the `docs` repo at `todo-api/sdk-artifacts/python/`. After changing `sdk/todo_client/`, run `make sdk-docs DOCS_REPO=../docs` (a checkout of the `docs` repo) and open a docs PR with the result.

## Docs

Published at [https://mintlify-demo.mintlify.site/todo-api](https://mintlify-demo.mintlify.site/todo-api) (sign-in required). The pages and the API spec live in the [`docs` repo, under `todo-api/`](https://github.com/mintlify-demo/docs/tree/main/todo-api), not here. This repo holds only code and tests. When a pull request here changes the API, Mintlify's *Update from code changes* automation opens a pull request in the `docs` repo with the matching docs update.
