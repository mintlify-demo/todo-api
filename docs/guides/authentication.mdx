Every endpoint requires an API key. Send it in the `X-API-Key` header.

```bash
curl http://localhost:8000/todos -H "X-API-Key: demo-key"
```

## Keys by plan

Each key belongs to a plan. The plan decides which endpoints the key can call.

| Key | Plan | Can call |
| --- | --- | --- |
| `demo-key` | Standard | Every endpoint except bulk create |
| `partner-demo-key` | Partner | Every endpoint except bulk create |
| `enterprise-demo-key` | Enterprise | Every endpoint, including [`POST /todos/bulk`](/todo-api/guides/enterprise-bulk-import) |

<Info>
  These demo keys are public on purpose. To use different keys, set `TODO_API_KEY`, `TODO_PARTNER_API_KEY`, and `TODO_ENTERPRISE_API_KEY` before you start the server.
</Info>

## What happens without a key

A missing or wrong key returns `401`:

```json
{ "detail": "Invalid or missing API key" }
```

## In the API playground

Each endpoint page in the API reference has an **Authorization** field. When you're signed in to the docs, it's filled in with your plan's key. Otherwise, enter `demo-key` there, and the playground adds the header for you.

<ParamField header="X-API-Key" type="string" required>
  Your API key. For the demo, use `demo-key`.
</ParamField>

<Warning>
  Never commit real API keys. This demo key is public on purpose.
</Warning>
