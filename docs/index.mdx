## Endpoints

| Method | Path | What it does |
| --- | --- | --- |
| `GET` | `/todos` | List todos (paginated, filterable) |
| `POST` | `/todos` | Create a todo |
| `GET` | `/todos/{todo_id}` | Get one todo |
| `PATCH` | `/todos/{todo_id}` | Update a todo |
| `DELETE` | `/todos/{todo_id}` | Delete a todo |
| `GET` | `/todos/list-all` | <Badge color="orange">Deprecated</Badge> List every todo, unpaginated |
| `POST` | `/todos/bulk` | <Badge color="purple">Enterprise</Badge> Create up to 100 todos at once |
| `POST` | `/graphql` | GraphQL queries and mutations |
| `WS` | `/ws/events` | Stream of `todo.created`, `todo.updated`, `todo.deleted` |

<Warning>
  Data lives in memory. Restarting the server clears every todo.
</Warning>
